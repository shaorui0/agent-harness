# 输出格式契约

**输出结构化、压缩、无描述性废话。** 实质性回复用这个骨架：

```
========= 【结论】 ==========================
- 一到三条，每条一行

========= 【证据】 ==========================
| 事实 | 出处 |
|---|---|

========= 【问题】 ==========================
- Q1：

========= 【下一步】 ========================
- [ ] 动作 | 谁 | 阻塞在什么
```

格式规则：

| 内容形态 | 用什么 |
|---|---|
| 并列项、动作、清单 | bullet，一行一条 |
| 多字段对照、状态矩阵、前后对比 | 表格 |
| 因果链、取舍论证 | 自然段，最多两三句 |

- 段名放 `【】`，分隔线用等号补到大致等宽
- 删掉过渡句、铺垫句、总结句。信息一条不丢，描述一句不留
- 数字、路径、`file:line`、命令原样给，不要转述
- 纯对话、简单确认、单点问答不受此约束
